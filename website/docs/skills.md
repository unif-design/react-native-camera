# 研发技能

[unif-portal-dev-skills](https://github.com/unif-skill/unif-portal-dev-skills) 用于团队与 Agent 协作维护代码。使用本库的 npm 包无需安装这些技能。

按任务选择入口：开发用 `code-development`，设计、测试、审查和交付分别用 `architecture-design`、`code-testing`、`code-review`、`code-delivery`。具体安装见技能仓库。

接口用法以所采用版本的公开类型与 API 文档为准；技能不包含产品运行时 Agent 指令。
