# 库能力与研发技能

`unif-camera` 用于本库的使用、维护和排障。技能在开发工具中使用，应用通过 npm 接入本库。

在 Codex 的 `unif-portal-dev-skills` 市场安装本库插件 `unif-camera`，并确认默认公共插件 `unif-platform-rules` 已启用。需要本库的 RN 工程约定和消费者验收资料时，可从 `unif-react-native-skills` 插件读取 `unif-rn-project`。读取私有技能仓需要相应权限和 Git 认证。[技能仓安装说明](https://github.com/unif-skill/unif-portal-dev-skills#安装与使用)

| 需要做什么 | 从哪里开始 |
|---|---|
| 查接口、接入或排查库能力 | 用 `unif-camera` 查采用版本的公开类型、示例和使用条件。 |
| 修改或验证库工程 | 从[本库开发资料](https://github.com/unif-design/react-native-camera/blob/main/docs/DEVELOPMENT.md)选择技能、源码入口和消费者验证。 |
| 设计、测试、审查或交付 | 按[工程技能分工](https://github.com/unif-skill/unif-portal-dev-skills#与-uni-技能的职责分工)选择本次任务的入口。 |

涉及其他自有库时按需查对应公开资料，已安装的能力技能可辅助定位。准确接口以采用版本的公开类型与文档为准；[LLM 文档索引](https://unif-design.github.io/react-native-camera/llms.txt) 声明构建版本，官网新能力不能直接当作旧依赖已支持。

技能源码和安装更新方式由技能仓维护，API 和示例由本库维护；生成文档从源重新生成，不复制维护第二份 API。
